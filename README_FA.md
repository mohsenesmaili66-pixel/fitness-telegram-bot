# ربات تلگرام مربی تناسب اندام

ربات فارسی برای برنامه هفتگی ورزش، راهنمای تغذیه عمومی، ثبت وزن و دور شکم، گزارش اندازه‌ها و یادآوری روزانه.

## امکانات
- برنامه هفتگی تمرین در خانه/پارک
- ارسال تمرین امروز
- راهنمای پایه تغذیه برای کاهش وزن
- ثبت وزن و دور شکم در SQLite
- گزارش ۱۰ ثبت آخر و تغییر وزن
- یادآوری روزانه قابل تنظیم
- تنظیم منطقه زمانی و پاک کردن داده‌های ثبت‌شده

## راه‌اندازی

### ۱) ساخت ربات در تلگرام
1. در تلگرام به `@BotFather` برو.
2. دستور `/newbot` را بفرست و نام و شناسه ربات را انتخاب کن.
3. توکن را دریافت کن. توکن را برای هیچ‌کس نفرست و در پیام عمومی منتشر نکن.

### ۲) نصب Python
Python 3.11 یا جدیدتر نصب کن.

### ۳) نصب وابستگی‌ها
در پوشه پروژه ترمینال باز کن و اجرا کن:

```bash
python -m venv .venv
```

فعال‌سازی محیط مجازی:
- Windows: `.venv\\Scripts\\activate`
- macOS/Linux: `source .venv/bin/activate`

سپس:
```bash
pip install -r requirements.txt
```

### ۴) تنظیم توکن
فایل `.env.example` را به `.env` تغییر نام بده و توکن خود را در `BOT_TOKEN` قرار بده.
کد به‌صورت خودکار فایل `.env` را بارگذاری می‌کند.

### ۵) اجرا
```bash
python bot.py
```
در تلگرام صفحه ربات را باز کن و `/start` بزن.

## دستورهای مهم
- `/start` شروع
- `/help` راهنما
- `/remind 19:30` یادآوری هر روز ساعت ۱۹:۳۰
- `/remind off` خاموش کردن یادآوری
- `/timezone Europe/Madrid` تنظیم منطقه زمانی
- `/reset` پاک کردن اندازه‌های ثبت‌شده و یادآوری

## اجرای ۲۴ ساعته
برای ارسال یادآوری در تمام روزها، برنامه باید روی کامپیوتر روشن یا یک سرور/میزبان همیشه‌روشن اجرا شود. اگر برنامه متوقف شود، یادآوری‌ها ارسال نمی‌شوند. برای میزبانی آنلاین، از سرویس معتبر پایتون استفاده کن و متغیرهای محیطی `BOT_TOKEN` و `BOT_TIMEZONE` را در تنظیمات سرویس قرار بده. پایگاه داده SQLite باید روی دیسک پایدار باشد؛ فایل‌سیستم‌های موقت ممکن است داده‌ها را حذف کنند.

## نکات ایمنی و حریم خصوصی
- توکن ربات را محرمانه نگه دار؛ اگر لو رفت، از BotFather توکن جدید بگیر.
- اطلاعات اندازه‌ها روی همان محیطی که ربات اجرا می‌شود ذخیره می‌شوند. از پوشه دیتابیس نسخه پشتیبان بگیر و دسترسی سرور را محدود کن.
- این برنامه ارزیابی پزشکی یا مربی حضوری نیست. در صورت بیماری زمینه‌ای، آسیب، درد قفسه سینه، سرگیجه یا تنگی نفس غیرعادی تمرین را متوقف کن و کمک پزشکی بگیر.
- کاهش چربی فقط از شکم با حرکت موضعی ممکن نیست؛ روند کاهش چربی کلی بدن و تغذیه پایدار مهم‌اند.
- برنامه ورزشی داخل کد نمونه‌ای عمومی است. اگر سابقه آسیب یا بیماری داری، پیش از تمرین پرفشار با متخصص مشورت کن.

## محدودیت فعلی
یادآوری‌ها در حافظه زمان‌بندی برنامه قرار دارند؛ پس از ری‌استارت، باید دوباره دستور `/remind HH:MM` را وارد کنی. نسخه بعدی می‌تواند زمان یادآوری‌ها را هنگام راه‌اندازی از پایگاه داده بازیابی کند.
